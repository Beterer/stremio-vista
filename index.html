Stremio Origin

A native TV app for Stremio addons, written in C, for LG webOS TVs.

Install

In the Homebrew Channel, add this repository, then install Stremio Origin:

https://stremio-origin.github.io/webos/apps.json

Or take the .ipk from Releases and install it in Developer Mode.
